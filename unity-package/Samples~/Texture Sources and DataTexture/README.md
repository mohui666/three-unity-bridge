# Texture Sources and DataTexture

This sample is generated by `npm run example:textures`. Its `.threeunity` file embeds a local PNG, a loopback-HTTP JPEG, and deterministic uint8, half-float, and float DataTextures; the source files and temporary HTTP server are not needed after generation.

Import the sample from Unity Package Manager, drag `texture-pipeline-v7.threeunity` into a Scene, and enter Play Mode. The panel layout demonstrates encoded-image orientation and sRGB sampling alongside raw R, RG, RGBA, RGB half, and RGBA float data, with point/bilinear/trilinear filtering, independent U/V wrap modes, mipmaps, and anisotropy preserved on the imported `Texture2D` subassets.

The sample needs no runtime loader or behavior script. Texture bytes are contained in the imported asset, and materials that reference the same texture id share one `Texture2D` subasset.
