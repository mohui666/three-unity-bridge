# Material UV Animation

This sample is generated by `npm run example:material`. It contains two meshes that share a Three.js material and a looping clip that animates base color, opacity, emission, roughness, and base-map offset/repeat.

Import the sample from Unity Package Manager, drag `material-uv-animation.threeunity` into a Scene, and enter Play Mode. The imported `ThreeUnityAnimationPlayer` starts the default clip automatically; no additional sample behavior script is required.
