# PBR Material Maps

This sample is generated by `npm run example:pbr`. It contains only deterministic geometry and embedded uint8 `DataTexture` pixels; it does not need a downloaded model, image, network request, or runtime texture loader.

Import **PBR Material Maps** from Unity Package Manager, drag `pbr-material-maps-v8.threeunity` into a Scene, and enter Play Mode. The four spheres demonstrate scalar-only PBR, a shared Three.js metalness/roughness source, separately packed metalness and roughness sources, tangent-space normal scaling, negative normal Y scaling, HDR emission intensity, and a looping rotation/emission pulse.

The importer creates linear `Metallic Smoothness` subassets from Three.js blue-channel metalness and green-channel roughness, and creates `Scaled Normal` subassets only where the two-axis `normalScale` cannot be represented by Unity's single `_BumpScale` value. These are import-time subassets; the sample does not create materials or textures during Play Mode.

Automated EditMode coverage checks the derived pixels, sampler and ST state, tangent conversion/recalculation, normal scaling, emission, animation, and shared identity. It does not replace a manual Game View review of highlight shape, normal direction, emission appearance, or shader rendering.
