# Line Points Sprite

This sample is generated by `npm run example:primitives`. It contains a continuous `Line`, independent `LineSegments`, a closed `LineLoop`, a grouped and vertex-colored `Points` cloud, and two textured `Sprite` objects with different centers, rotations, scales, and size-attenuation modes.

Import the sample from Unity Package Manager, drag `non-mesh-primitives.threeunity` into a Scene, and enter Play Mode. The imported camera shows all six render objects, while `ThreeUnityAnimationPlayer` rotates the continuous line, floats the point cloud, pulses the centered sprite, and animates that sprite's color and opacity. No additional sample behavior script is required.
